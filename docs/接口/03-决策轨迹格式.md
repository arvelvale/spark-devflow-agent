# 接口 3：决策轨迹格式（`var/runs/<session>/trace.jsonl`）

状态：**已冻结 v1（2026-09-24 晨熠确认）**。只增不改，要改先找负责人。代码侧定义在 `agent/trace.py`（`EVENT_TYPES` 与 `validate_event`）。

决策轨迹是 agent 每一个结构化决策的流水账：选了哪个技能、概率多少、走本地还是云端、哪个工具被门控拦下、压缩丢了什么。**Web 面板、A/B 数据、演示视频都只读它**，所以它是三方共用的契约。

## 行格式

每行一个 JSON 对象（UTF-8，不转义中文）：

```json
{"v": 1, "ts": "2026-09-24T10:03:12.481+08:00", "session": "s-20260924-100301-a1b2", "turn": 3, "seq": 17,
 "type": "skill.select", "latency_ms": 812, "provider": "jev", "model": "jev-1.13.0",
 "usage": {"input_tokens": 530, "output_tokens": 80}, "fallback": false,
 "data": { ... 见下表 ... }}
```

| 公共字段 | 必有 | 说明 |
|---|---|---|
| `v` | 是 | 格式版本，目前 1 |
| `ts` | 是 | ISO 8601，带时区 |
| `session` | 是 | 会话 ID |
| `turn` | 是 | 第几轮（从 1 起；会话级事件为 0） |
| `seq` | 是 | 会话内单调递增序号 |
| `type` | 是 | 事件类型，见下表 |
| `data` | 是 | 事件内容 |
| `latency_ms` | 否 | 这一步耗时 |
| `provider` / `model` | 否 | 这一步用的服务（`jev` / `local` / `backup` / `cloud`）和实际模型版本 |
| `usage` | 否 | `{"input_tokens", "output_tokens"}` |
| `fallback` | 否 | true = 这一步走了降级链路（JEV 不可用、模型切换等） |

## 事件类型与 `data`

| type | 何时 | data 主要字段 |
|---|---|---|
| `turn.start` | 收到用户输入 | `input`、`source`（text / voice） |
| `skill.select` | 技能选择完成 | `mode`（jev / baseline）、`selected`（技能名列表）、`gate`（三个门控 Noul 与均值）、`stage1`（各技能概率）、`stage2`（各候选 fits）、`reason` |
| `route.model` | 本轮模型路由 | `tier`（local / cloud）、`endpoint`、`reason`、`scores`（难度概率等） |
| `route.escalate` | 轮内升级/切换模型 | `from`、`to`、`reason` |
| `memory.recall` | 记忆召回与精选 | `candidates`（id、关键词分）、`full`、`brief`、`dropped`（id 与 relevant 值）、`excluded_private` |
| `llm.call` | 每次主模型调用 | `tier`、`step`、`finish_reason`、`tool_calls`（名字列表）、`prompt_tokens_est` |
| `tool.gate` | 每次工具调用前 | `tool`、`permission`、`decision`（allow / confirm / deny）、`appropriate`、`threshold`、`confirmed`、`reason` |
| `tool.call` | 工具执行后 | `tool`、`args`（长字段截断）、`ok`、`result_chars`、`truncated` |
| `context.compress` | 发生压缩 | `phase`（tool_results / turns）、`before_tokens`、`after_tokens`、`chunks`（id、verdict、score）、`archive` |
| `memory.write` | 轮末记忆写回 | `items`（id、layer、kind、status、worth） |
| `turn.end` | 本轮结束 | `stopped`（final / max_steps / error）、`steps`、`reply_chars`、`tokens`（按 local / cloud / jev 分开） |
| `error` | 任何异常 | `where`、`message`、`handled`（是否已降级处理） |

## 约定

1. **只增不改**：新增字段、新增事件类型都可以；已有字段不改名、不改语义。确实要改就把 `v` 升到 2。
2. **轨迹里不出现密钥**；工具参数里超过 500 字的字段截断成"前 200 字…[共 N 字]"。
3. 读取方要忽略不认识的事件类型和字段（向前兼容）。
4. 轨迹是调试和展示用的，**不是**会话原文。会话原文和压缩前的原始记录在同目录的 `archive.jsonl`。
